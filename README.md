# Kurs Mechatronik Praxis

Teilnehmer:
Sam Miller


Lasten: 
    MUSS:
    • Ein zu entwickelndes Fahrzeug muss autonom von einem Startpunkt einer schwarzen Linie folgen.
    • Info: Die schwarze Linie besteht aus Modulen des „RoboCup Standards“ und werden eine Woche vor dem Wettbewerb festgelegt (Parcour-Vorstellung).
    • Das Fahrzeug muss über das Folgen der Linien ein Zielgebiet erreichen. Es ist dabei mit Kreuzungen und Kurven zu rechnen.
    • Das Fahrzeug muss ein Hindernis auf dem Weg bis in den Zielbereich transportieren
    • Im Zielgebiet muss das Fahrzeug drei Kugeln in unterschiedlichen Farben möglichst effizient finden und anfahren.
    • Im Zielgebiet müssen die Kugeln (2 Kugeln einer Farbe, 1 Kugel mit einer anderen Farbe) sortiert und so abgelegt werden, dass nur die 2 Kugeln der gleichen Farbe in einem dafür vorgesehenen Bereich abgelegt werden, aber alle drei Kugeln vorher vom Fahrzeug aufgenommen wurden.
    Danach wird das Fahrzeug gestoppt

    SOLL:
    • Das Fahrzeug soll möglichst kostengünstig, dennoch robust konstruiert und aufgebaut werden
    • Das Fahrzeug soll möglichst schnell den Weg zum Ziel finden, um den Robocup auf Zeit am Ende der Projektphase zu gewinnen.
